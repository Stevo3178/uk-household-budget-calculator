# Free UK Household Budget Calculator — Goldcrest Guides

A responsive, dependency-free household budget calculator for UK users.

## Features
- Enter monthly take-home income and household costs.
- View monthly income, costs, balance/shortfall, and annual estimates.
- Print or save the results as a PDF.
- Reset all amounts to zero.
- Figures are calculated locally in the browser and are not sent to Goldcrest Guides by this page.
- Includes a link to the separate UK Household Budget Planner product.

## Publish with GitHub Pages
1. Upload `index.html` and `README.md` to the root of your public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Important note
This calculator provides general budgeting estimates based on user-entered figures. It is not personalised financial advice or regulated financial advice.
